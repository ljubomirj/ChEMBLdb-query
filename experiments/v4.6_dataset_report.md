# V4.6 Benchmark Dataset Report

**Benchmark:** v4.4_final (95 cases)

## Overview

This dataset contains 95 executable ChEMBL text-to-SQL pairs harvested from multiple public sources and processed into a standardized benchmark for evaluating LLM-generated SQL queries against the ChEMBL 36 SQLite database.

## Dataset Composition

| Query Family | Count | Description |

| Exact-ID assays | 15 | Specific assay lookups by CHEMBL ID |

## Case Structure

Each case directory contains:
```
<case_id>/
├── source.sql              # Original SQL from source
├── sqlite.sql              # SQLite-adapted SQL
├── ground-truth.csv        # Expected results (or .csv.zst)
├── ground-truth.csv.zst    # Compressed version

```

## Quality Controls

**Inclusion criteria:**
1. SQL executes successfully on ChEMBL 36
2. Results are deterministic (sorted, normalized)
3. Ground truth is materialized and verified
4. Case has clear semantic intent
5. No duplicate cases (deduplicated by ID+UQ)

**Exclusion:**
- 6 document cases with malformed CSVs (ragged lines in SMILES)
- 4 assay cases with corrupted ground truth
- Duplicate entries across scraping rounds

## Usage

**Run full benchmark:**
```bash
uv run python3 experiments/evaluate_prompt_pack_v4.py \
  --prompt-pack-path experiments/prompt_pack_v4.6.yaml \
  --split-file experiments/case_splits_v4.4_final.json \
  --split train --split val --split test \
  --eval-root experiments/evals/baseline \
  -- --multi-endpoint-profile zai-glm-4.7-anthropic
```

**Access case data:**
```python
import json
cases = json.loads(open("tests/cases/web_scrape_hq_cases.json"))
for case in cases:
    print(f"{case['id']}: {case['uq']}")
```
